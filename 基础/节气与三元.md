# 节气与三元

时家奇门起局需要先辨阴阳遁，再辨节气、三元。阴阳遁、局数和三元分别回答顺逆、起宫及所处阶段的问题。

## 阴遁与阳遁

冬至后用阳遁，夏至后用阴遁，是节气起局的基本分界。阳遁、阴遁各有一至九局，合称阴阳十八局。某时具体使用哪一局，还须依节气及上、中、下元判断。

## 三元与符头

五日为一元，三元为一组。以甲日、己日为符头，符头的地支决定该元属于上、中、下哪一元。

| 符头地支 | 元别 |
| --- | --- |
| 子、午、卯、酉 | 上元 |
| 寅、申、巳、亥 | 中元 |
| 辰、戌、丑、未 | 下元 |

例如甲子为上元符头，随后己巳为中元符头，甲戌为下元符头。这里的日符头用于分元；[六甲旬首](旬首旬空与驿马.md)用于十个干支一旬，两个概念不能混用。

## 节气与符头的配合

节气交接与每五日的符头并不总能整齐重合，因此有超神、接气、置闰等配合节令与三元的论法，也有其他定局法。局数表只列定局后的对应，不能单独代替完整历法与定局程序。

《超神接气诀》涉及特定闰法，阅读其“节”“气”“先到”等词时，应依全篇理解。见[卷六·超神接气诀](../古籍/奇门遁甲秘笈大全/06-卷六.md#超神接气诀)。
