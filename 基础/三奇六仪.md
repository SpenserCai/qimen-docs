# 三奇六仪

奇门遁甲以乙、丙、丁为三奇，以戊、己、庚、辛、壬、癸为六仪。甲隐于六仪之下，故称“遁甲”。

## 三奇

| 天干 | 名称 | 阴阳五行 |
| --- | --- | --- |
| 乙 | 日奇 | 阴木 |
| 丙 | 月奇 | 阳火 |
| 丁 | 星奇；亦称玉女 | 阴火 |

“日奇”“月奇”“星奇”为奇门中的专名，不宜只凭通常的日月阴阳印象重新配属。

## 六甲与六仪

| 六甲旬首 | 所遁六仪 | 仪干五行 |
| --- | --- | --- |
| 甲子 | 戊 | 阳土 |
| 甲戌 | 己 | 阴土 |
| 甲申 | 庚 | 阳金 |
| 甲午 | 辛 | 阴金 |
| 甲辰 | 壬 | 阳水 |
| 甲寅 | 癸 | 阴水 |

“甲子戊”表示甲子旬的甲遁在戊下。甲仍属阳木，戊仍属阳土；遁藏关系不改变天干原有的五行。

## 地盘奇仪次序

常用排列次序为：**戊、己、庚、辛、壬、癸、丁、丙、乙**。

阳遁按宫数顺布，阴遁按宫数逆布；遁几局，戊便从几宫起。这里的顺逆首先指宫数次序，不等于沿九宫图边框顺时针或逆时针走一圈。

例如阳遁一局，按一至九宫依次为：戊、己、庚、辛、壬、癸、丁、丙、乙。

## 得奇与成格

某宫有乙、丙、丁，可以称得奇；要成三奇得使、玉女守门、九遁等格，还须满足各格的奇仪、门、神、宫位条件。不能只因得奇就认定所有吉格同时成立。
