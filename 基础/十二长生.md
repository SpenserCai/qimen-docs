## 十二阶段

| 阶段 | 基本含义 |
| --- | --- |
| 长生 | 萌生、生长 |
| 沐浴 | 初生之后，尚待安定 |
| 冠带 | 渐成形貌 |
| 临官 | 成长而能任事；亦称禄地 |
| 帝旺 | 气势极盛 |
| 衰 | 盛后渐退 |
| 病 | 气力受损 |
| 死 | 生机止息 |
| 墓 | 收藏、归藏；亦称库 |
| 绝 | 前气断绝 |
| 胎 | 新气孕育 |
| 养 | 蓄养待生 |

这些是阶段名称，不能把“病”“死”等字直接当作人的现实诊断或生死结论。

## 查表方法

先确定所查天干，再确定地支。例如甲见亥为长生，甲见寅为临官，甲见未为墓。由地支归宫时，亥在乾，寅在艮，未在坤。

一个四维宫含两个地支，必须说明具体取哪一个支。不能因为乾宫有戌，就忽略同宫还有亥，将所有干落乾宫都称为入墓。

三奇入墓、时干入墓及六仪击刑另见[刑墓与门迫](../专题/格局/刑墓与门迫.md)。十二长生与按月令判断旺相休囚属于不同方法，见[旺衰](旺衰.md)。
