# 八神

常用八神为值符、螣蛇、太阴、六合、白虎、玄武、九地、九天，表示各类神意与作用性质。

## 基本取象

| 八神 | 主要取象 | 取象重点 |
| --- | --- | --- |
| 值符 | 元首、贵重、统领、护持 | 居首与统摄 |
| 螣蛇 | 惊恐、怪异、虚诈、缠绕 | 虚惊与变化 |
| 太阴 | 阴匿、暗中、荫护、私事 | 隐藏与细密 |
| 六合 | 婚姻、交易、媒介、和合 | 联系与协同 |
| 白虎 | 兵戈、杀伐、争斗、刑伤 | 刚猛与损伤 |
| 玄武 | 阴谋、盗失、逃亡、隐情 | 暗昧与潜藏 |
| 九地 | 坤土、柔顺、安静、伏藏 | 静守与承载 |
| 九天 | 乾金、刚健、行动、显扬 | 高举与开展 |

“腾蛇”常作“螣蛇”；“元武”与“玄武”在古文中并见。查找时可以兼检这些字形。

## 五行异说

八神的五行配属有异说，不宜用一张表掩盖差异。

| 神名 | 常见八神配法 | 《九神主论章》所述 |
| --- | --- | --- |
| 值符 | 土 | 火 |
| 螣蛇 | 火 | 丁火之气，其实属阴土 |
| 太阴 | 阴金 | 阴金 |
| 六合 | 木 | 东方之阴木 |
| 白虎 | 金 | 庚金 |
| 玄武 | 水 | 水之精 |
| 九地 | 坤土 | 坤土 |
| 九天 | 乾金 | 乾金 |

比较神与其他要素的生克之前，必须先确定采用哪种配法。基本取象与五行配属是两层内容，不能只因某一配法不同便改写古文。

## 勾陈、朱雀、太常

| 神名 | 《九神主论章》属性 | 主要事类 |
| --- | --- | --- |
| 勾陈 | 中央阳土 | 田土、勾连、词讼 |
| 朱雀 | 丙火 | 文书、印信、口舌 |
| 太常 | 五行之化气 | 宴享、祭祀、衣帛、酒食 |

古籍有不同神名组合。《九神主论章》虽以“九神”为题，章内实际论到十一神；这些神名不表示每一种排法都同时布列十一位。转盘、飞盘以及兼用其他术数的章节，应分别阅读。

## 值符的两个层次

八神值符与当旬领值的九星不是同一个要素。古文亦以“值符”称领值之星或旬首之仪，须按上下文辨认。见[天地盘与值符值使](天地盘与值符值使.md)。
