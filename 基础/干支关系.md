# 干支关系

## 天干五合

| 相合 | 合化所配五行 |
| --- | --- |
| 甲己 | 土 |
| 乙庚 | 金 |
| 丙辛 | 水 |
| 丁壬 | 木 |
| 戊癸 | 火 |

“相合”与“成化”不是同一个判断。两干相见可论合；是否按化气论，要看所用法则与条件，不能把两干各自的五行直接删除。

## 天干四冲

甲庚冲、乙辛冲、丙壬冲、丁癸冲。戊己居中，不列入这四组。

## 地支六合、六冲、六害、六破

| 关系 | 六组配对 |
| --- | --- |
| 六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未 |
| 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 |
| 六害 | 子未、丑午、寅巳、卯辰、申亥、酉戌 |
| 六破 | 子酉、丑辰、寅亥、卯午、巳申、未戌 |

六合的合化另有细分；例如午未有合而不化、合土等不同论法。应与所用章节保持一致。六破并非所有奇门占法都取用。

## 三合

| 三合组 | 所合五行 |
| --- | --- |
| 申子辰 | 水 |
| 亥卯未 | 木 |
| 寅午戌 | 火 |
| 巳酉丑 | 金 |

三合组也用于记忆驿马的位置。三合与六合的配对规则不同。

## 相刑

| 类别 | 支的关系 |
| --- | --- |
| 子卯相刑 | 子刑卯，卯刑子 |
| 寅巳申三刑 | 寅刑巳，巳刑申，申刑寅 |
| 丑未戌三刑 | 丑刑戌，戌刑未，未刑丑 |
| 自刑 | 辰、午、酉、亥各自相见 |

六仪击刑是六甲所含地支与落宫地支形成特定刑的关系，不能只按仪干的五行相克推定。对应表见[刑墓与门迫](../专题/格局/刑墓与门迫.md)。

## 关系的层次

天干五合与地支六合是两套配对；八神中的“六合”则是神名。三个“合”应分别记录。冲合的含义还与动静、占题有关，不能把“合”无条件等同于成事，把“冲”无条件等同于失败。
