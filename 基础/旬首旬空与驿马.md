# 旬首、旬空与驿马

## 六十甲子与旬首

十天干与十二地支按次序配合，组成六十甲子。每十组为一旬，每旬从甲起，故有六个旬首。

| 旬首 | 旬中范围 | 所遁六仪 | 旬空 |
| --- | --- | --- | --- |
| 甲子 | 甲子至癸酉 | 戊 | 戌、亥 |
| 甲戌 | 甲戌至癸未 | 己 | 申、酉 |
| 甲申 | 甲申至癸巳 | 庚 | 午、未 |
| 甲午 | 甲午至癸卯 | 辛 | 辰、巳 |
| 甲辰 | 甲辰至癸丑 | 壬 | 寅、卯 |
| 甲寅 | 甲寅至癸亥 | 癸 | 子、丑 |

每旬只有十个地支参与配干，余下两个称旬空。日旬空由日柱所属旬查得，时旬空由时柱所属旬查得；查哪一柱应先说明。

例如丙寅属甲子旬，旬首甲子遁戊，空亡戌亥。

## 空亡与宫位

| 空亡地支 | 对应宫 |
| --- | --- |
| 戌亥 | 乾六 |
| 申酉 | 申在坤二，酉在兑七 |
| 午未 | 午在离九，未在坤二 |
| 辰巳 | 巽四 |
| 寅卯 | 寅在艮八，卯在震三 |
| 子丑 | 子在坎一，丑在艮八 |

两个空支可能同居一宫，也可能分属两宫。所谓半空、全空，以及出空、填实、冲空的论法，须保留支与宫的区别。

## 驿马

| 所据地支属于 | 驿马 | 马星所在宫 |
| --- | --- | --- |
| 申子辰 | 寅 | 艮八 |
| 寅午戌 | 申 | 坤二 |
| 巳酉丑 | 亥 | 乾六 |
| 亥卯未 | 巳 | 巽四 |

日马以日支查，时马以时支查。《驿马、劫煞》歌用日支；时家奇门中也有以时支论马的用法。两者查表关系相同，所据时间不同，不应省略“日”“时”。

## 日禄

| 天干 | 禄支 |
| --- | --- |
| 甲 | 寅 |
| 乙 | 卯 |
| 丙、戊 | 巳 |
| 丁、己 | 午 |
| 庚 | 申 |
| 辛 | 酉 |
| 壬 | 亥 |
| 癸 | 子 |

日禄、驿马和旬空各自独立，不能因同落一宫便合并成一个概念。
