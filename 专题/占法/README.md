# 占法

| 条目 | 内容 |
| --- | --- |
| [主客与取用](主客与取用.md) | 先辨彼此主客，再辨星、门、宫的层次。不同占题另有取用，不把一种主客分法套到所有占法。 |
| [出行与行人](出行与行人.md) | 出行、访人、远信、归期各有取用；先按所问事项查篇，再比较相关宫位。 |
| [财物与交易](财物与交易.md) | 求财、借贷及财产的问法分别取用。财物遗失另见失物与捕盗。 |
| [婚姻与人事](婚姻与人事.md) | 婚姻、延师、访道、宴请等人事各有主客和取用。 |
| [失物与捕盗](失物与捕盗.md) | 失物、走失、捕捉、失畜分篇查阅，物象与寻找条件分开辨认。 |
| [仕宦与科名](仕宦与科名.md) | 仕宦、荐举与科举按具体事项分列，保留古代制度中的名称。 |
| [词讼](词讼.md) | 词讼诸篇分别论原被告、问官、干证、状词及牵连，不把不同篇目的用神强行合并。 |
| [天时与地理](天时与地理.md) | 雪、水道、河水、布种、迁居、坟墓分别列篇。 |
| [兵事](兵事.md) | 兵占按投军、攻守、敌情和胜负分篇；主客随占题确定。 |
| [杂占](杂占.md) | 雀噪、梦象、怪异与身命等篇，保留古代占验的事类划分。 |
| [医药占条](医药占条.md) | 占病、请医等古籍篇目 |
