# 射覆

射覆指覆藏物件而推求其物。奇门射覆常涉及宫卦、星、门、奇仪的类象；类象分别描述物类、形态、色泽、味与数，不是一见某宫便只对应某一物。

## 九宫物类

《奇门遁甲元灵经》卷二十三的射覆篇依一白至九紫列物类。下表保留各条字句，便于逐项查阅。

| 宫色 | 物类、数与色 |
| --- | --- |
| 一白 | 猪肉、酒食、海味、茨蒜、地栗、有蒂核之物，数目一六，皂白者。 |
| 二黑 | 野味、牛肉、肚子、甘物、五谷、山羊、竹笋、花生、布棉之类，数八、十、五之数，黑黄色者。 |
| 三碧 | 竹笋、花木之物，鱼肉、果豆、菜蔬、酸味、茶叶、檀香、笔扇，数目四、八、三之数，色青蓝、月白。 |
| 四绿 | 禽鸟之类，鸡、虫、蔬果、酸味、木花香、绳纤长细之物，数目四、五、八，青蓝色者。 |
| 五黄 | 五谷、野味、牛肉、肚子，甘物，方物，墨布、棉之类，山药、竹笋、芋、花菇、花生，数目五、十、八，色黄黑者。 |
| 六白 | 马肉、圆物、木果、天鹅、虎豹皮、象、珠玉、金银，数目一、六、九，色白。 |
| 七赤 | 羊肉、鱼、蟹、美味、金银铜废器，有口物，数目二、十、九，色白赤。 |
| 八白 | 狗肉、禽、鼠、瓜果、蚬子、甜物，数目五、一、八，色玄黄。 |
| 九紫 | 鸡肉、烧炙、煎炒之物，龟螺、甲胄、书纸，数目二、七、九，苦味，色红紫者。 |

## 宫色与宫数

| 宫色 | 九宫 | 五行 |
| --- | --- | --- |
| 一白 | 坎一 | 水 |
| 二黑 | 坤二 | 土 |
| 三碧 | 震三 | 木 |
| 四绿 | 巽四 | 木 |
| 五黄 | 中五 | 土 |
| 六白 | 乾六 | 金 |
| 七赤 | 兑七 | 金 |
| 八白 | 艮八 | 土 |
| 九紫 | 离九 | 火 |

“宫色”是宫的数色名，不等于覆物一定具有的颜色。例如二黑条另列“黑黄色者”，七赤条另列“色白赤”。条文中的取数也不等于只取该宫宫数。

## 物类的层次

可以先分别记录物的类别、形状、色泽、滋味、数量，再察这些特征如何组合。例如“有口物”“圆物”“绳纤长细之物”描述的是形态；金银、五谷、禽鸟描述的是物类。

同一物可能兼有多个象，同一象也可对应多物。本篇给出物类条目，未在这九条中完整规定起局与取用方法，不能将物象表直接当作完整射覆程序。
