# 刑、墓与门迫

## 六仪击刑

六仪击刑取六仪所遁六甲的地支，与落宫地支论刑。

| 六仪 | 六甲 | 落宫 | 所论之刑 |
| --- | --- | --- | --- |
| 戊 | 甲子 | 震三 | 子刑卯 |
| 己 | 甲戌 | 坤二 | 戌刑未 |
| 庚 | 甲申 | 艮八 | 申刑寅 |
| 辛 | 甲午 | 离九 | 午自刑 |
| 壬 | 甲辰 | 巽四 | 辰自刑 |
| 癸 | 甲寅 | 巽四 | 寅刑巳 |

六仪是表面所见之干，击刑所论的是所遁六甲之支。不能把戊落木宫受克，直接当作击刑的定义。

## 三奇入墓

《烟波钓叟歌》列乙临坤二、丙临乾六、丁临艮八为三奇入墓。这一歌诀口径与十干阴阳顺逆的十二长生表存在差异：后者乙木墓在戌，歌诀则以乙临未宫论墓。

| 三奇 | 歌诀所列墓宫 | 对应支 |
| --- | --- | --- |
| 乙 | 坤二 | 未 |
| 丙 | 乾六 | 戌 |
| 丁 | 艮八 | 丑 |

查古法三奇墓格时，应按该格的规定；查十干十二运时，应按[十二长生](../../基础/十二长生.md)表。两种乙木墓位不能悄然合为一个。

## 时干入墓

《烟波钓叟歌》列戊戌、壬辰、丙戌、癸未、丁丑等时干入墓组合。这里以时干与时支成组说明，与天盘干落某墓宫是不同的表达层次。

## 门迫

门克宫为门迫。《烟波钓叟歌》：“宫制其门不为迫，门制其宫是迫雄”。

| 八门五行 | 门迫所临宫 |
| --- | --- |
| 休门水 | 离九火 |
| 生门、死门土 | 坎一水 |
| 伤门、杜门木 | 坤二、中五、艮八土 |
| 景门火 | 乾六、兑七金 |
| 惊门、开门金 | 震三、巽四木 |

表列五行关系；中宫能否安门，仍须依所用排法，不能仅凭此表添加第九门。宫克门则是门受宫克，有另称“宫迫”者，应与这里的门迫分辨。

《奇门占事》对特定用事另有“门尅宫吉”的论法，与歌诀的门迫论述并不相同。应完整保留各段的对象和条件，不能拼成一条普遍规则。

## 五不遇时

五不遇时以时干克日干、且阴阳同类为条件。例如甲日庚时，庚金克甲木，阳克阳；乙日辛时，辛金克乙木，阴克阴。它比较的是时干与日干，不是星门落宫。
