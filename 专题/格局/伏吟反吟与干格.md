# 伏吟、反吟与干格

## 伏吟

星或门回到本位，称该星或该门伏吟。例如天蓬临坎一为星伏吟，休门临坎一为门伏吟；上下一样的奇仪相加，亦有奇仪伏吟之称。

须说明所论的是星、门、奇仪还是全局。局部一项伏吟，不等于整盘所有要素都伏吟。古法常从静、滞、反复等方面取义，具体吉凶仍依占事。

## 反吟

反吟亦写作“返吟”。星、门临本位对冲之宫，称该项反吟。例如天蓬本位坎一，移至离九，为星反吟。

| 本位宫 | 对冲宫 |
| --- | --- |
| 坎一 | 离九 |
| 坤二 | 艮八 |
| 震三 | 兑七 |
| 巽四 | 乾六 |

反吟所说的“反”是相对于本位的对冲关系，不能直接等同于阴遁逆布。

## 庚、丙相加

| 格名 | 条件 |
| --- | --- |
| 太白入荧 | 庚加丙 |
| 荧入太白 | 丙加庚 |

庚称太白，丙称荧惑。上下方向相反，格名和古文所论的主客进退也不同。

## 飞、伏与庚格

| 名称 | 条件 |
| --- | --- |
| 伏干 | 天盘庚加地盘日干 |
| 飞干 | 天盘日干加地盘庚 |
| 伏宫 | 庚加值符所指之仪 |
| 飞宫 | 值符所指之仪加庚 |
| 大格 | 庚加癸 |
| 刑格 | 庚加己 |
| 上格 | 庚加壬 |

“飞干”在不同篇章还可指门内暗藏之干。见[主客与取用](../占法/主客与取用.md)，不要将同名的两种含义合并。
