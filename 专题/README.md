| 条目 | 内容 |
| --- | --- |
| [主客与取用](占法/主客与取用.md) | 先辨彼此主客，再辨星、门、宫的层次。不同占题另有取用，不把一种主客分法套到所有占法。 |

| [失物与捕盗](占法/失物与捕盗.md) | 失物、走失、捕捉、失畜分篇查阅，物象与寻找条件分开辨认。 |
| [仕宦与科名](占法/仕宦与科名.md) | 仕宦、荐举与科举按具体事项分列，保留古代制度中的名称。 |

| [杂占](占法/杂占.md) | 雀噪、梦象、怪异与身命等篇，保留古代占验的事类划分。 |
| [医药占条](占法/医药占条.md) | 占病、请医等古籍篇目 |
